# Jeriel Martinez Portfolio

A modern, animated portfolio built with React, SCSS, Three.js, and Vite.

## Features
- Animated hero section with custom cursor and 3D background
- Projects showcase with interactive 3D scene
- Rocket launch transition to experience timeline
- Responsive, mobile-optimized, and accessible
- Smooth scrolling and scroll-based animations

## Tech Stack
- React 19
- SCSS Modules
- Three.js / @react-three/fiber
- Framer Motion
- GSAP + ScrollTrigger
- Lenis (smooth scroll)
- Vitest + Testing Library

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```
2. **Run the dev server:**
   ```bash
   npm run dev
   ```
3. **Build for production:**
   ```bash
   npm run build
   ```
4. **Run tests:**
   ```bash
   npm test
   ```

## Folder Structure
- `src/components` – React components
- `src/styles` – SCSS modules and global styles
- `src/assets` – Images, fonts, and 3D models
- `public/` – Static files
